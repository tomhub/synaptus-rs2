Scope

This is one scan on one computer. FFT engines, compilers, CPUs, thread settings, and data can change the ordering. It is not a language-wide ranking.

Short version: lower median = faster here. Similar ranges = do not over-read a tiny gap.

This compares these implementations and their numerical libraries, not programming languages in isolation. Both Rust ports use release builds and the configured Rayon worker count. Octave and NumPy common math thread settings are limited to one.
