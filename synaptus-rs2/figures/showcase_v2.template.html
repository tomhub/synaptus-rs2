raccoon

The raccoon found these by going through the original's frequency bins, which is what raccoons do with bins. A Stolt factor applied twice, a depth grid missing its bottom end, and a frequency axis labelled three quarters of a bin from where the samples are.

Scoreboard

What changed, in three numbers

MULOK, pins

Envelope error against the exact integral: the original, then v2's default. The bugs are off by default; the faithful copy runs only when called as legacy::mulok.

PSM, wires

How far the original PSM is from the integral it approximates. Not a bug: a rectangle rule. v2's SQ-PSM computes the integral itself, if you ask for it with psm_sq.

CPSM, pipe

How much the pipe image changes once the cylindrical code stops treating a 64° arc as a full circle. No exact answer exists to grade either side, so this is a difference, not an error.

Four scans, before and after

Same rules for all four tabs: the left side is the original code (through the faithful Rust copy, which matches it to 1e-15); the right side is v2. Error maps use one log scale, from 10⁻⁵ (black) to 10⁻¹ (pale) of the brightest pixel.

badger

The badger checked the black right-hand error maps on the wires and holes tabs and is unimpressed. SQ-PSM is the exact reference there, so of course its error map is black. Its real exam was an independent oracle on other data, where it agreed to within 4.1e-11. The badger still wants a second badger to check that.

Status: tested by the implementer, independent verification pending. "Exact" means the m → ∞ limit of PSM's own model; the physics model (angle-independent transmission, scalar waves) is the same on both sides, so neither side is more right about the specimen.
